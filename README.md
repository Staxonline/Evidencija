# Евиденција едукације

Апликација за евиденцију едукације психотерапеута-едуканата: едукације, групна и индивидуална супервизија, радионице (са сертификатима) и лична терапија. Збир по школској години, извоз у CSV и PDF.

Сви подаци се чувају **само на уређају** (IndexedDB у прегледачу). Ништа се не шаље на сервер. Резервна копија је један JSON фајл који корисник сам чува и увози.

Инсталација: отвори адресу у Chrome-у (Android) или Safari-ју (iPhone) и изабери „Додај на почетни екран“ / „Инсталирај апликацију“.
